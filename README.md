# Shahna & Nadhir — Wedding invitation website

Open `index.html` in a browser to preview. For hosting, upload this entire folder to Netlify Drop or deploy as a static site to Netlify/Vercel. No build step required.

## Features
- Drag or tap to open the paper invitation and reveal the main page
- Continuous falling petals along both edges
- Responsive cinematic sections and scroll reveals
- Wedding countdown (31 December 2026, midnight India time)
- Family invitation and Google Maps search directions
- Reduced-motion accessibility support

## Confirm before publishing
- The invitation card lists **Royal Convention Centre, Pirappancode** while the supplied location says **Royal Palace Convention Centre, Pirappancode, Manikkal**. The website uses the supplied location, but confirm the venue name.
- Wedding time was not provided, so it is intentionally omitted. The countdown targets the beginning of the wedding date, not the ceremony time.
- The Hijri date is copied from the supplied card without independent verification.
